# RCT projected fixture

`Example_Tree_RCT_projected.laz` is a **synthetic test location**, not real
georeferencing. It preserves the shape and attributes of `Example_Tree_RCT`,
translates XYZ by (481000, 5313000, 700) metres and assigns EPSG:32632 for
testing projected inputs and the internal packing helper's origin precision.

It is generated by the RCT repository's `tests/make_projected_fixture.py`.
The original fixture is unchanged and has no CRS. Both fixtures work with the
regular RCT wrapper, which no longer exposes GLB export.
